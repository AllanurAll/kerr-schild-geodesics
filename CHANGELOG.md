# Changelog

## v1.0.0 — Undergraduate reconstruction

- Reconstructed the Kerr metric in Cartesian Kerr–Schild coordinates.
- Replaced the original symbolic-to-Fortran workflow with a Python/Numba numerical kernel.
- Added fixed-step fourth-order Runge–Kutta integration.
- Validated exact Schwarzschild and Kerr circular timelike geodesics.
- Added conserved-energy and angular-momentum diagnostics.
- Added ZAMO frame-dragging calculations.
- Added generic bound Kerr and Schwarzschild trajectory visualizations.
- Added null geodesics, photon capture/scattering, and parallel-ray capture maps.
- Added automated physics tests and continuous integration.
